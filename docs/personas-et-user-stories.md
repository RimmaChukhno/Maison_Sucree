# Personas et User Stories - Maison Sucrée

1. Personas

## Persona 1 - Camille

Âge : 28 ans
Ville : Marseille
Profession : Graphiste
Camille habite à Marseille et aime acheter du pain et des pâtisseries dans les petites boulangeries. Elle utilise surtout son téléphone.
Elle cherche :
voir rapidement les produits ;
connaître les prix ;
trouver les horaires ;
voir où se trouve la boulangerie.
Problème : elle n’aime pas les sites compliqués où il faut chercher longtemps une information.

## Persona 2 - Thomas

Âge : 35 ans
Ville : Lyon, en visite à Marseille
Profession : Ingénieur
Thomas est à Marseille pour quelques jours. Il cherche une boulangerie locale et veut découvrir les spécialités.
Il cherche :
voir les produits ;
comprendre ce que contient chaque produit ;
connaître les prix ;
trouver l’adresse et les horaires.
Problème : quand il visite un nouveau lieu, il a besoin de trouver les informations rapidement.

## Persona 3 - Sophie

Âge : 42 ans
Ville : Marseille
Profession : Enseignante
Sophie achète parfois des gâteaux pour des anniversaires ou des événements. Elle utilise son ordinateur et son téléphone.
Elle cherche :
voir les différents gâteaux ;
connaître les prix ;
avoir quelques informations sur les ingrédients ;
pouvoir ajouter plusieurs produits à une commande.
Problème : elle n’aime pas quand les informations importantes sont difficiles à trouver.

2. User Stories

User Story 1 - Voir les produits
En tant que client, je veux voir les produits de la boulangerie afin de choisir ce qui m’intéresse.
User Story 2 - Filtrer les produits
En tant que client, je veux filtrer les produits par catégorie afin de trouver plus facilement ce que je cherche.
User Story 3 - Voir un produit
En tant que client, je veux ouvrir la page d’un produit afin de voir sa photo, son prix et sa description.
User Story 4 - Ajouter un produit
En tant que client, je veux ajouter un produit à ma commande afin de préparer mon panier.
User Story 5 - Modifier le panier
En tant que client, je veux voir et modifier mon panier afin de vérifier ma commande.
User Story 6 - Trouver la boulangerie
En tant que client, je veux trouver l’adresse et les horaires afin de pouvoir aller à la boulangerie.
User Story 7 - Voir les ingrédients
En tant que client, je veux voir les ingrédients principaux afin de savoir ce que contient le produit.
