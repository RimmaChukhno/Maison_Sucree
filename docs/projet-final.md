# Maison Sucrée — Document projet final (synthèse)

## 1. Vue d’ensemble

**Maison Sucrée** est une boulangerie-pâtisserie artisanale fictive à Marseille.  
Projet académique Da Vinci : démontrer le processus UI/UX complet en 4 jours.

## 2. Problème

Permettre de découvrir les produits, comprendre l’offre (prix, détails), préparer une commande simple et trouver les infos pratiques — sans site complexe.

## 3. Utilisateurs

Camille (locale), Alex (touriste), Sophie (cadeau) — voir `research.md`.

## 4–6. Recherche

Concurrents, questionnaire, décisions UX — voir `research.md` et `ux.md`.

## 7. User flows

Découverte produit · Ajout commande · Trouver la boutique.

## 8. Wireframes

`docs/wireframes/wireframes.md`

## 9–10. UI & prototype

Design system dans `css/style.css` + pages HTML.  
Figma haute fidélité à réaliser Day 2 (composants listés dans `ux.md`).

## 11. Développement

HTML5 · CSS3 · JavaScript vanilla · localStorage · pas de backend.

## 12–13. Tests & améliorations

`docs/testing.md` (résultats simulés étiquetés + itérations badge / toast / horaires).

## 14. Résultat

Site multi-pages responsive prêt pour démo et code review.
