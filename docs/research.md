# Maison Sucrée — Recherche UX

> Projet académique Da Vinci (4 jours)  
> Document de recherche — ne pas confondre avec des données clients réelles.

---

## 1. Vue d'ensemble du projet

**Maison Sucrée** est une boulangerie-pâtisserie artisanale fictive située à Marseille.  
Le site web doit permettre de découvrir les produits, consulter les informations essentielles et préparer une commande simple — sans complexité e-commerce.

---

## 2. Problème utilisateur

Les utilisateurs veulent rapidement :

- découvrir les produits ;
- comprendre ce qui est disponible (prix, détails) ;
- trouver adresse et horaires ;
- préparer une commande simple.

Sans naviguer dans un site trop dense ou commercial.

## 4. Analyse concurrentielle (UX)

Sites analysés (sites réels, analyse UX — pas un jugement « joli / pas joli ») :

| Site | Type |
| ---- | ---- |
| **A — La Dacquoise** (ladacquoise.fr) | Boulangerie-pâtisserie Marseille |
| **B — Poilâne** (poilane.com) | Boulangerie artisanale premium |
| **C — Du Pain et des Idées** (dupainetdesidees.com) | Boulangerie parisienne artisanale |

### 4.1 Site A — La Dacquoise

| Critère | Observation UX |
| ------- | -------------- |
| Navigation | Simple (accueil, produits, contact) — peu de pages |
| Accueil | Texte informatif + catégories ; hero peu dominant |
| Menu | Présentation par blocs textuels, peu de filtres |
| Cartes produit | Photos limitées ; descriptions générales |
| Détails produit | Peu de fiches détaillées (prix / allergènes) |
| Commande | Contact téléphone / formulaire — pas de panier |
| Contact | Adresse, téléphone, formulaire visibles |
| Hiérarchie | Correcte mais dense en texte |
| Mobile | Correct, parfois long à scroller |
| **Forces** | Local clair (Marseille), contact facile, ton artisanal |
| **Faiblesses** | Prix peu visibles, pas de filtrage, pas de parcours commande |

### 4.2 Site B — Poilâne

| Critère | Observation UX |
| ------- | -------------- |
| Navigation | Claire, marque forte |
| Accueil | Identité visuelle forte ; storytelling |
| Menu / boutique | Catalogue e-commerce structuré |
| Cartes produit | Images soignées, prix visibles en boutique |
| Détails | Fiches complètes |
| Commande | E-commerce complet (hors scope petite boutique) |
| Contact | Adresses multi-boutiques |
| Hiérarchie | Très soignée |
| Mobile | Bonne expérience |
| **Forces** | Clarté produit, prix, parcours d’achat fluide |
| **Faiblesses** | Trop « grand commerce » pour une petite maison locale ; surcharge fonctionnelle |

### 4.3 Site C — Du Pain et des Idées

| Critère | Observation UX |
| ------- | -------------- |
| Navigation | Minimaliste |
| Accueil | Atmosphère artisanale forte |
| Menu | Mise en avant de spécialités |
| Cartes produit | Visuels beaux, infos parfois limitées |
| Détails | Variable selon section |
| Commande | Orienté visite / histoire plus que panier |
| Contact | Présent mais parfois secondaire |
| Hiérarchie | Esthétique > utilitaire |
| Mobile | Correct |
| **Forces** | Ambiances, crédibilité artisanale |
| **Faiblesses** | Prix / filtres / commande moins prioritaires |

### 4.4 Tableau comparatif

| Fonctionnalité | La Dacquoise (A) | Poilâne (B) | Du Pain et des Idées (C) |
| -------------- | ---------------- | ----------- | ------------------------ |
| Navigation claire | Oui | Oui | Oui |
| Filtrage produits | Non | Oui (boutique) | Non |
| Détails produit | Partiel | Oui | Partiel |
| Prix visibles | Rarement | Oui | Rarement |
| Commande / panier | Non (contact) | Oui | Non |
| Infos contact | Oui | Oui | Oui |
| UX mobile | Moyen+ | Bon | Moyen+ |

### 4.5 Opportunité pour Maison Sucrée

Se positionner **entre** :

- la simplicité locale (A / C) ;
- la clarté produit + panier léger (inspiré de B, sans e-commerce lourd).

→ Site petit, élégant, avec **prix, filtres, fiche produit, panier simple, contact**.

## 5. Questionnaire utilisateur (6–8 questions)

Destiné à 5–10 personnes (amis, famille, camarades).

1. À quelle fréquence achetez-vous viennoiseries / pâtisseries en boulangerie ?
2. Quelle information cherchez-vous en premier sur le site d’une boulangerie ?
3. Qu’est-ce qui compte le plus pour choisir une pâtisserie ?
4. Préférez-vous parcourir les produits par catégorie ?
5. Utiliseriez-vous un panier / commande en ligne simple (retrait) ?
6. Qu’est-ce qui rend un site food difficile à utiliser ?
7. Sur quel appareil consulteriez-vous le site le plus souvent ?
8. Quelles infos devraient toujours être visibles (horaires, adresse, prix…) ?

## 6. Résultats d’échantillon (simulés — clairement identifiés)

> **Important :** les résultats ci-dessous sont un **échantillon simulé** pour le projet académique.  
> Ce ne sont **pas** des données de terrain réelles.  
> En conditions réelles, le même questionnaire serait diffusé à 5–10 personnes.

**Profil simulé :** 8 répondants (étudiants + actifs, 20–45 ans).

| Question | Tendance principale (simulée) |
| -------- | ----------------------------- |
| Q1 Fréquence | 5/8 = 1 à 2 fois / semaine |
| Q2 Info en premier | Prix (6/8), horaires (5/8), photos (4/8) |
| Q3 Critère choix | Apparence / photo (7/8), prix (6/8), allergènes (3/8) |
| Q4 Catégories | Oui, préféré (7/8) |
| Q5 Panier simple | Oui, utile (6/8) |
| Q6 Difficultés | Trop de texte, prix cachés, menu confus |
| Q7 Appareil | Mobile (6/8), desktop (2/8) |
| Q8 Toujours visible | Horaires, adresse, prix |

---

## 7. Décisions UX dérivées de la recherche

| Résultat (simulé) | Décision UX |
| ----------------- | ----------- |
| Prix cherchés en premier | Afficher le prix sur chaque carte produit |
| Navigation par catégories | Filtres All / Cakes / Pastries / Bread / Drinks |
| Panier simple utile | Panier localStorage, sans paiement |
| Horaires / adresse critiques | Présents Accueil + Contact + Footer |
| Mobile majoritaire | Design responsive prioritaire |
| Photos importantes | Images produit sur cartes + fiche détail |
| Sites trop denses | Accueil épuré : hero, spécialités, best-sellers |

---

## 8. Synthèse

Maison Sucrée doit être :

**petit + clair + chaleureux + fonctionnel**

Priorités : découverte produit → filtres → détails → panier → localisation.
